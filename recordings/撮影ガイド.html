🎬 MOTTAINAI 撮影ガイド

あんたがやるのは、画面を操作しながら4回録画ボタンを押すだけ。
喋らなくていい（音声なしで成立する構成）。顔も出ない。字幕・繋ぎ・書き出しは全部こっちでやる。

準備（初回だけ・3分）

OBSの録画設定（保存先・画質・1080p30・MP4）はもう作ってある。起動すればその設定で立ち上がる。
  1. OBSを起動する（L:\obs-studio\bin\64bit\obs64.exe）
  2. 初回に「自動構成ウィザード」が出たら 「いいえ」または「キャンセル」。設定は作成済みなので不要
  3. 画面の中央に自分のデスクトップが映っていればOK。真っ黒なら↓の「映らない時」へ
  4. 右下の 「録画開始」 が押せる状態ならもう準備完了

映らない時（黒いままの場合）

  1. 左下「ソース」の ＋ → 画面キャプチャ を選ぶ
  2. 名前はそのままでOK →「OK」
  3. 「ディスプレイ」でメインの画面を選ぶ →「OK」

※画面が3枚あるので、選ぶディスプレイを間違えると別のモニタが映る。プレビューを見て、今使ってる画面が映るものを選ぶ。

録画の開始／停止は右下の「録画開始」ボタン。 保存先は L:\10\claude_demo\mottainai\recordings。 撮ったファイルはそこに溜まるので、撮り終わったら「終わった」とだけ言ってくれれば、こっちで拾って仕上げる。

撮る前に開いておくもの

  • タブ1：本番サイト https://mottainai-720945218465.asia-northeast1.run.app
  • タブ2：適当なPC構成診断サイト or BTOショップのおすすめ構成ページ（比較用。何でもいい）
  • タブ3：GitHub https://github.com/makoto680/mottainai
ブックマークバーは隠しておく（Ctrl+Shift+B）。個人的なブックマークが審査員に見えるのを防ぐため。 通知が出ないよう、集中モードにしておくと安全。

撮る内容（4カット）

1カットずつ「録画開始 → 操作 → 録画停止」。噛んでもそのカットだけ撮り直せばいい。順番通りに撮れば、こっちで繋ぐ。

カット1目安 20秒 — 問題を見せる
やること：タブ2（他社の診断サイト）を開いて、おすすめ構成のところをゆっくりスクロールするだけ。 値段が出ている部分が映るとなお良い。
ここに乗る字幕（こっちで焼く）：
"Every PC advisor answers the same way: buy more.
The more expensive the build, the more the site earns."
カット2目安 60秒 — 実際に使う（一番大事）
やること：タブ1（本番サイト）で以下を順に。ゆっくりでいい。
  1. トップが見えるところで2秒止まる（タグラインを読ませる間）
  2. CPU欄に i5-7500 と入力
  3. グラフィック欄に 内蔵 と入力
  4. メモリ＝8GB、ストレージ＝HDD を選ぶ
  5. 用途は 「Web・動画視聴・Office（事務）」 だけ選ばれている状態にする
  6. 「これで調べる」を押す
  7. エージェントのパネルが動くところをそのまま映しておく（約15〜20秒かかる。ここが「並列で動いてる」画）
字幕：
"Hand it your machine and what you actually do with it.
Two agents start at once — one reads the hardware, one reads the workload.
Then the verdict is computed. Not by a model — by ordinary, tested code."
カット3目安 45秒 — 結果を見せる
やること：カット2の結果が出た画面で、上から下へゆっくりスクロール。
  1. 大きい見出し（替えるのはストレージ1点だけ）で3秒止まる
  2. 金額の3つ（必要な出費／よくある診断の薦め／使わずに済む）で3秒止まる
  3. 部位ごとの表をゆっくり流す。ストレージ行の「この用途に必要なのは256GB」の注記で3秒止まる
  4. Windows 11 の欄まで下げて、選択肢が3つ出ているところで止まる
字幕：
"A 2017 office machine. The CPU is fine. The graphics card is not something to buy at all.
One part holds it back: the hard drive. 9,990 yen. Not a new computer.
It sizes the fix to the need — a 1TB drive does not imply a 1TB replacement."
カット4目安 40秒 — 中身とGoogle Cloud（要件）
やること：
  1. タブ3（GitHub）を開いて、READMEの先頭を2〜3秒映す
  2. core フォルダを開いて verdict.js を少しスクロール（2〜3秒）
  3. 用意したコマンド窓に切り替える（こっちで中身は仕込んでおく）。 自己検証が通る画面と Cloud Runで動いている証明が順に出る
字幕：
"Models perceive and explain. Deterministic code decides.
A tool that argues from cost cannot afford a hallucinated price.
Running on Cloud Run with Gemini 3.7 Flash."

カット4のコマンド窓について

あんたが打つ必要はない。録画用_証明画面.bat をダブルクリックするだけで、 自己検証38項目 → Cloud Runのサービス情報、の順に自動で流れる。それを録画すればいい。 （recordings フォルダの中にある）

撮り終わったら

「終わった」とだけ言ってくれればいい。
